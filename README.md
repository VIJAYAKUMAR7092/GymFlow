# 💪 GymFlow

A modern Gym Management System built using React, Django REST Framework, and PostgreSQL.

---

## Features

- User Authentication
- Admin Approval
- Dashboard
- Member Management
- Membership Plans
- Payments
- Attendance
- Reports
- Settings

---

## Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS

### Backend
- Django
- Django REST Framework

### Database
- PostgreSQL

---

## Installation

### Backend

```bash
cd backend
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
